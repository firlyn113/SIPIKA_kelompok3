Ringkasan Alur Perizinan Otomatis

Di SIPIKA, Anda tidak perlu memilih validator secara manual. Sistem akan secara otomatis menentukan alur persetujuan berdasarkan durasi ketidakhadiran yang diajukan:

  • < 1 Hari: Mahasiswa → Dosen → Admin Jurusan
  • = 1 Hari: Mahasiswa → Dosen → Ketua Jurusan / Sekjur → Admin Jurusan
  • > 1 Hari: Mahasiswa → Dosen → Ketua Jurusan / Sekjur → BAAK → Admin Jurusan
